# Crochet — интерактивная игра о вязании

**Игра в браузере:** https://alexaxel.github.io/crochet/

Кинематический прототип **воздушной петли**, не обучающий сайт и не иллюстрация схем. Весь экран — деревянный стол. На нём лежат клубок, маркеры, две запасные спицы; **работает один крючок**, поскольку воздушная петля при вязании крючком выполняется одним крючком. Все предметы генерируются кодом, ассеты художника пока не требуются.

## Управление

- **1** — выполнить воздушную петлю. Крючок захватывает участок рабочей нити и тянет новый сгиб через старую рабочую петлю.
- **2** или **Backspace** — распустить последнюю петлю. Во время анимации отменяет текущую операцию.
- **R** — начать цепочку с самого начала.
- **Space** зарезервирован под переход к новому ряду, **пока недоступен**.
- Мышь — вращение и масштаб для просмотра пересечений под разными углами.
- Кнопка шестерёнки — цвет пряжи, темп анимации, звук, подсветка рабочей петли и клавиши.

Выполняется **только одна техника: воздушная петля**. Никаких имитаций СБН, прибавок и носков в текущей игровой сцене нет.

## Что меняется в коде во время нажатия

- src/core/chainMechanics.ts: модель одной непрерывной нити; свободный хвост, начальный скользящий узел, законченные звенья цепочки, активная петля на крючке и рабочий конец к клубку. Во время операции новое U-образное колено рабочей нити захватывается и проходит **от отрицательного Z к положительному Z через отверстие предыдущей петли**. Вновь вытянутая петля становится активной, а старая затягивается. Количество готовых петель увеличивается только после протягивания.
- src/render/ChainTable.ts: каждую фазу перестраивает **ту же непрерывную пространственную кривую**, используя TubeGeometry. Крючок движется вместе с точкой захвата. Материал пряжи и клубок генерируются процедурно. Никакой заранее нарисованной картинки отдельной петли нет.
- src/main.ts: игровой ввод и закрытые по умолчанию настройки.
- tests/chainMechanics.test.ts: проверка цельности пути, фактического 3D-перехода сквозь предыдущую петлю, движения крючка, состояния машины и распускания.

## Честные ограничения

**Это ранняя кинематическая симуляция взаимодействия крючка с рабочей нитью, а не физически проверенное вязание.** На данный момент нет моделирования трения, взаимодействий пряжи с пряжей, натяжения, сохранения всех топологических инвариантов при сглаживании кривой или экспертной верификации того, как выглядит каждая дужка. Наличие Z-перехода доказывает **только локальное протягивание**, а не аутентичность всей готовой цепочки.

Поэтому один эксперт должен посмотреть сначала *одну* воздушную петлю, а затем *две-три последовательные*. Ключевые вопросы: что крючок захватывает, откуда проходит новая петля, где оказывается старая, как соединены две соседние петли. Если какая-либо стадия неверна, меняется сама геометрия/кинематика в chainMechanics.ts, а не текстура или декоративная анимация.

Старые src/core/model.ts, src/core/geometry.ts, src/render/YarnScene.ts и src/learn/lesson.ts остаются в репозитории как ранние эксперименты, но **не используются в приложении**.

## Разработка

    npm install
    npm test
    npm run dev
    npm run build

После изменения main GitHub Actions автоматически запускает build:pages и помещает готовые файлы в main/docs; затем GitHub Pages публикует сайт.

Последовательность следующих этапов после экспертного принятия воздушной петли: надёжная топология цепочки → моделирование реальных операций СБН через то же ядро → выбор способа ввода крючка → схемы и изделия → художественная полировка и Unity.
